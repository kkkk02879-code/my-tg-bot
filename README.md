# Telegram Echo & Utility Bot

Простой Telegram-бот на Python (`pyTelegramBotAPI`), который умеет отвечать на базовые команды и повторять отправленный текст.

## Команды

- `/start` — приветствие и краткий список команд
- `/help` — справка по доступным функциям
- `/roll [N]` — случайное число от `1` до `N` (по умолчанию от `1` до `6`)
- `/ping` — проверка статуса бота (`Pong!`)
- Любой другой текст — бот повторяет отправленное сообщение
